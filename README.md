# 孢粉演替台（Pollen Succession Stage）

湖芯孢粉计数的分带分析本地服务：在**数量 / 相对比例 / 方差稳定变换（arcsin √p）**三种口径间切换，
按研究者选择的**分母分类组**与**低计数排除阈值**重新分带，并对每个相邻（或相邻组合）样本间隙
保留**多个生态带边界候选**。固定柱样（fixture）随二进制发布，每次分带固定词表与年代模型版本，
运行记录可导出、可在清空数据库后重新导入并**重算复核**。

## 数据口径（务必先读）

- **零与缺失严格区分**：计数为 `0` 表示观察到但为零；`null` 表示未观察/未记录（缺失）。
  固定柱样 `S4` 中 Betula/Alnus 为 `0`，其余为 `null`，界面分别显示为 `0` 与“缺失”。
- **零总数不生成全零百分比**：当样本无任何观察计数（总计数为 0）时，不产生百分比/比例/
  反正弦值，也不进入组成分析；不会出现把“无数据”伪装成“各分类单元都是 0%”的全零行。
  低总计数样本（默认分母总计数 < 30）可由阈值开关排除，二者在界面标注不同原因。
- **混层样本不是精确边界**：`mixed=true` 的样本（固定柱样 `S5`、`S6`）若出现在边界两侧块内
  或被跨越的间隙内，该候选只能标记为“混层·仅可能方向”，仍给出最可能的升降分类单元，
  但不能作为精确边界。
- **年代多峰不平均**：边界候选的年代解释由边界两侧块及间隙内样本的年代区间聚合而成；
  区间**相交或相接即合并**为一个峰，**不相交则保留多个区间峰**。系统绝不把多峰平均成
  单一年份点。固定柱样两套年代模型刻意给出两种方案：
  - `am_2019`：S8/S9 区间相交，合并为单峰 `880–1090 cal BP`；
  - `am_2024`：S8/S9 与 S6/S8（跨越被排除的低计数 S7）区间不相交，保留双峰。
- **分母改变即重算**：切换进入分母的分类组（或自定义分类单元清单）会改变每个样本的分母总数、
  排除判定、组成与边界支持度；每次运行都记录固定词表指纹 `vocabulary_hash` 与固定柱样指纹
  `fixture_hash`。
- **支持度（组间差异）**：数量口径用块内池化计数的 Bray–Curtis；比例口径用比例向量的
  全变差距离（即比例 Bray–Curtis，∈[0,1]）；方差稳定口径用 arcsin √p 变换后的欧氏距离，
  归一化到 [0,1]。三种支持度在同一张边界卡上同时展示，当前口径决定排序。
- **相邻样本组合**：块大小 `k` 把纳入样本按深度顺序每 `k` 个池化为一块，块间间隙作为候选；
  间隙内因低计数/零总数被排除的样本会在候选上列为“跨越样本”。

固定柱样为教学/验收数据 `fixtures/fixture.json`（站点 LAKE-A，10 个样本、7 个分类单元、
5 个预设分母组：`all` / `pollen_only` / `trees` / `upland_pollen` / `herbs`）。

## 安装

```bash
cargo fetch --locked
```

技术栈：Rust（edition 2021）+ Axum 0.7 + SQLite（rusqlite，bundled libsqlite3，无需系统库）+
无外部依赖的单页 Web UI。

## 运行（演示/验收）

```bash
cargo test --locked && cargo run --locked -- --listen 127.0.0.1:5572
```

浏览器访问 <http://127.0.0.1:5572>，页面标题为 **“孢粉演替台”**。

可选参数：

```bash
cargo run --locked -- --listen 127.0.0.1:5572 --db ./pollen-stage.sqlite3
```

首次启动若库内没有固定柱样会自动写入；若库内柱样与随程序发布版本不一致，会覆盖并清空旧运行。

## 页面上做什么

1. 选择**分母分类组**（或填自定义分类单元清单覆盖分组）、低计数阈值、块大小 `k`、
   年代模型版本、视图口径，点“运行分带”。
2. 查看**边界候选**：精确/混层标记、三种口径支持度、可能支持方向、年代区间峰
   （多峰带红色标记且不平均）、跨越的排除样本、各分类单元贡献百分点。
3. 查看**组成曲线**（深度纵轴，浅→深；混层橙线、排除样本灰虚线、边界红/橙横线）与
   **原计数表**（`缺失` 与 `0` 不同样式，非分母分类单元标注“非分母”）。
4. 验收建议路径：
   - 分母组从 `all` 切到 `pollen_only`，观察 S8/S9 等候选的词表指纹与支持度变化；
   - 阈值取 30 时 S7 被排除、S4 因零总数被排除（原因不同）；阈值取 0 时 S7 纳入但 S4 仍排除；
   - 同一边界在 `am_2019` 单峰、`am_2024` 双峰，确认没有被平均成年份点；
   - 混层 S5/S6 两侧的候选只能是模糊候选，但仍显示方向。

## 运行记录：导出与重放复核

- “导出全部运行记录”（`GET /api/export`）下载 JSON 包；单条可用 `/api/runs/{id}/export`。
- “导入运行记录重放复核”（`POST /api/replay`）**不直接采信**导出里的结果：服务端用导出中的
  输入参数在当前固定柱样上**重新计算**，校验 `fixture_hash` 并把重算结果与导出结果逐字段比较；
  只有完全一致才落库，被篡改或柱样版本不符的条目拒绝并在报告中标明 `body_match=false`。
- “清空运行”删除全部运行；“清空数据库并重导固定柱样”（`POST /api/admin/reset`，
  `{"scope":"all"}`）保留数据库文件、重写固定柱样并清空运行；随后即可用导出包重放复核。

## HTTP API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 健康检查 |
| GET | `/api/fixture` | 固定柱样与 `fixture_hash` |
| POST | `/api/runs` | 运行分带（body 为分带参数） |
| GET | `/api/runs` | 历史运行列表 |
| GET / DELETE | `/api/runs/:id` | 查看 / 删除一次运行 |
| GET | `/api/runs/:id/export` | 导出单条运行 |
| GET | `/api/export` | 导出全部运行包 |
| POST | `/api/replay` | 导入并重新计算复核 |
| POST | `/api/admin/reset` | `{"scope":"runs"}` 或 `{"scope":"all"}` |

POST `/api/runs` 参数示例：

```json
{
  "group": "all",
  "denominator_taxa": null,
  "min_total": 30,
  "block_size": 1,
  "age_model": "am_2024",
  "transform": "angular"
}
```

`transform` 取值：`counts` / `proportion` / `angular`；自定义分母时传
`"denominator_taxa": ["Betula", "Quercus"]` 并把 `group` 置空。

## 测试

```bash
cargo test --locked
```

包含 11 个统计单元测试（区间合并/多峰、零总数无百分比、零与缺失区分、低计数排除、
混层模糊方向、分母切换改变支持度、三种变换、块大小、非法分母）与 8 个 HTTP 集成测试
（首页标题、API 行为、篡改重放拒绝、清空重导后原样重放通过等）。

## 目录

- `fixtures/fixture.json` — 固定柱样（随程序编译进二进制，亦落库于 `meta` 表）
- `src/models.rs` — 固定柱样模型与零/缺失校验
- `src/stats.rs` — 词表指纹、变换、组间差异、边界候选、年代区间合并
- `src/db.rs` — SQLite 持久化、导出包
- `src/web.rs` — Axum 路由、重放复核
- `assets/` — 单页 Web UI（原生 JS/SVG，无外部依赖）
- `tests/api.rs` — HTTP 集成测试

数据库文件默认 `pollen-stage.sqlite3`（已 gitignore，可用 `--db` 指定）。
